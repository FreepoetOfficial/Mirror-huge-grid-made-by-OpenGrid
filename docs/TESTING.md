# 测试与验收

## 自动测试

在仓库根目录运行：

```bash
python -m unittest discover -s tests -v
python -m compileall -q app.py thermal_guard.py shadow tests
```

测试覆盖地址布局、列优先像素打包、板块旋转、I²C 分块写入、按键读取、按键全局坐标、涟漪亮度、剪影完整性、亮度梯度、曝光变化、主体选择、残影重建和温控回差。

## 实机验收表

- [ ] `i2cdetect -y 1` 显示 0x24–0x2F 共 12 块
- [ ] 服务重启后自动进入 active
- [ ] API 中 camera 为 picamera2，而不是 synthetic
- [ ] API 中 output 为 I²C，hardware_error 为空
- [ ] 稳态帧率接近 12 FPS
- [ ] 网页的 24×32 图案与实体同位置、同方向
- [ ] 左上角实体为 1000/0x27，右下角为 0011/0x2C
- [ ] 每块板显示方向相同，没有单板转置或镜像
- [ ] 人进入后轮廓完整，非剪影处基本无散点
- [ ] 人离开后按设定渐弱，固定残影能被重建清除
- [ ] 实体可见多级亮度，而非只有开/关
- [ ] 每块板至少测试一个按键，涟漪源位置正确
- [ ] 涟漪传播时相机剪影仍连续更新
- [ ] 重启树莓派后无需登录即可自动运行
- [ ] 达到温控阈值时保护逻辑能按预期动作（生产设备不要用人为堵风方式测试）

## 回归原则

改变映射或旋转时至少运行相关单测并对照网页/实体。改变处理算法时使用相同机位、背景和光照录制前后对比；只凭单帧截图很难评估残影与柔和过渡。改变 I²C 频率或按键轮询量时，应连续运行并观察 FPS、硬件错误与总线重连。
